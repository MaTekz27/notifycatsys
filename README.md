# NotifyCatSys

Backend-сервис для создания и отправки email-уведомлений.

## Используемые технологии

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Maven

## Возможности

* Создание уведомлений через REST API.
* Хранение уведомлений в PostgreSQL.
* Асинхронная отправка писем.
* Периодическая обработка ожидающих отправки уведомлений.
